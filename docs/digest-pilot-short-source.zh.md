# 导论

本书讨论企业与契约之间的关系。企业把许多交易放进一个组织内部完成。契约则规定组织内外各方可以做什么。本书用两个模型说明这一关系。第一个模型说明契约为何不完全。第二个模型说明专用性投资如何决定企业的边界。

## Intro.1 为什么存在企业

企业存在的原因是市场失灵。1937 年科斯在《企业的性质》中提出这一判断。他指出，使用价格机制本身有成本。寻找交易对手要花时间，谈判要花成本，履约要花监督成本。当这些成本高于组织内部的协调成本时，交易就进入企业。这个判断把企业看作价格机制的替代物。它同时给出一个可检验的方向：交易成本越高，企业越大。

# 第一章 不完全契约

## 1.1 契约为何不完全

契约不完全是因为未来或然情形无法被事先完全描述。当事人的语言有限，写入契约的条款也有限。即使能够描述全部情形，把每一种情形都写进契约的成本也可能超过收益。第三方还常常无法验证当事人观察到的信息。于是契约留下空缺，需要事后重新谈判。本书把这一判断称为有限描述假设。第一章和第二章的两个模型都依赖这一条假设，因此它是两个模型共享的前提。

## 1.2 剩余控制权

所有者持有剩余控制权。剩余控制权指契约没有写明的那些决定权。Hart 在 1995 年论证了剩余控制权的配置决定专用性投资的激励。把剩余控制权给投资方，投资方就有动力提高专用性投资。把剩余控制权给另一方，投资方就担心事后被压价。这个机制把产权配置与投资激励连在一起，也为下一章的形式模型提供了直觉。

# 第二章 一个形式模型

## 2.1 模型设定

委托人选择专用性投资水平 x。投资成本是 c(x)。假设 c(x) 是严格凸函数，并且 c(0) 等于 0。投资提高交易对方获得的收益 v(x)。假设 v(x) 是严格凹函数，并且 v(0) 等于 0。双方先签订契约，再投资，最后重新谈判。契约只能规定一个初始价格。投资水平无法写入契约，因为第三方无法验证。这一设定把有限描述假设变成一个可计算的环境。

## 2.2 均衡与结果

一阶条件给出最优投资水平 x*。在契约完全时，x* 满足边际收益等于边际成本。在契约不完全时，投资方只得到新增收益的一部分。于是 x* 低于最优水平，投资不足出现。这个结果给出可检验的含义：剩余控制权越偏向投资方，投资越接近最优。数据显示，专用性投资水平提高了 12%，样本期为 1980 年至 1990 年。数据还显示，控制权配置改变之后，投资调整在两年内完成。
