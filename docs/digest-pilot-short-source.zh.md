# 导论

本书讨论企业与契约之间的关系。企业把许多交易放进一个组织内部完成。契约则规定组织内外各方可以做什么。本书用两个模型说明这一关系。第一个模型说明契约为何不完全。第二个模型说明专用性投资如何决定企业的边界。

本书的问题来自一个观察。现实中的企业规模差别很大。有的企业只雇用几个人。有的企业雇用几十万人。契约同样是现实制度的中心。有的契约只有一页。有的契约长达数百页。本书追问两个问题。什么决定企业的边界。什么决定契约的详略。

本书的方法是比较制度。我们把两种安排放在同一个环境里比较。一种是市场交易，一种是组织内部交易。两种安排面对同样的不确定性，也面对同样的当事人。我们比较它们的成本，也比较它们的激励。这个方法不预测某一家企业的具体规模。它只给出方向性的含义。

本书的材料分三层。第一层是历史的观察。第二层是形式模型。第三层是经验证据。三层材料互相约束。历史观察提出问题。形式模型给出机制。经验证据检验方向。任何一层单独出现都不足以支持结论。

本书的安排如下。第一章讨论契约的不完全。第二章给出一个形式模型。两章共享一条前提。这条前提在第一章提出，在第二章变成可计算的环境。读者先读第一章，再读第二章，会看到同一条前提的两种用法。

本书的适用范围有限。我们讨论专用性投资可以观察、但无法写入契约的情形。我们不讨论纯粹的金融合约。我们也不讨论跨国法律差异。这些题目需要另外的框架。本书只在给定的范围内给出判断。

## Intro.1 为什么存在企业

企业存在的原因是市场失灵。1937 年科斯在《企业的性质》中提出这一判断。他指出，使用价格机制本身有成本。寻找交易对手要花时间。谈判要花成本。履约要花监督成本。这些成本合起来就是交易成本。当交易成本高于组织内部的协调成本时，交易就进入企业。这个判断把企业看作价格机制的替代物。它同时给出一个可检验的方向。交易成本越高，企业越大。

交易成本有几个组成部分。第一是搜寻成本。买方要知道谁在卖，卖方要知道谁在买。第二是谈判成本。双方要就价格、数量、交付时间达成一致。第三是履约成本。一方要确认另一方按约定行事。第四是调整成本。环境变化后，双方要重新谈判。这四类成本都随交易复杂度上升。

组织内部也有成本。管理者要分配任务。管理者要监督执行。管理者要传递信息。层级越多，信息传递越慢。组织越大，激励越弱。所以企业不会无限扩大。企业的边界出现在两种成本相等的地方。这一点是科斯判断的补充，而不是反驳。

这个判断留下一个问题。如果企业只是价格机制的替代物，为什么企业内部的安排差别很大。有的企业内部靠指令。有的企业内部靠内部契约。这个差别需要一个关于契约的理论。第一章给出这个理论的第一步。

# 第一章 不完全契约

本章讨论契约为何留下空缺。我们先把空缺的来源分开。然后说明空缺的后果。最后说明本书采用的前提。这一章不建立模型。它只固定后面要用的概念。

契约是当事人对未来行为的约定。约定的内容可以是价格，也可以是行动。约定的形式可以是书面，也可以是口头。契约的用处是减少不确定性。当事人知道对方要做什么，就可以安排自己的投入。契约的局限是它无法覆盖所有情形。

## 1.1 契约为何不完全

契约不完全是因为未来或然情形无法被事先完全描述。当事人的语言有限。写入契约的条款也有限。即使能够描述全部情形，把每一种情形都写进契约的成本也可能超过收益。第三方还常常无法验证当事人观察到的信息。于是契约留下空缺，需要事后重新谈判。本书把这一判断称为有限描述假设。第一章和第二章的两个模型都依赖这一条假设。因此它是两个模型共享的前提。

有限描述假设有三个来源。第一个来源是语言。自然语言有歧义。同一个词在不同情形下含义不同。第二个来源是成本。写清每一种或然情形需要律师、会计师和工程师的时间。第三个来源是不可验证。当事人能观察到状态，法院不能。三个来源各自独立。任何一条成立，契约就不完全。

契约不完全有直接后果。当事人知道契约会有空缺。所以在签约时，双方会争夺空缺处的决定权。这个争夺就是剩余控制权的来源。第二章的模型把这一点写成投资激励。第一章只提出概念。概念的用处是让后面的模型有明确的对象。

有限描述假设也解释了契约的详略。当或然情形容易描述时，契约可以写得很细。当或然情形难以描述时，契约只能写原则。原则留下解释空间。解释空间带来事后谈判。事后谈判改变事前的投资激励。这条链条是本书的主线。

## 1.2 剩余控制权

所有者持有剩余控制权。剩余控制权指契约没有写明的那些决定权。这些决定权包括如何使用资产、与谁交易、如何分配收益。所有者不需要在每一种情形下重新谈判。他直接决定。这个安排节省了谈判成本。它同时把风险集中到所有者身上。

Hart 在 1995 年论证了剩余控制权的配置决定专用性投资的激励。把剩余控制权给投资方，投资方就有动力提高专用性投资。把剩余控制权给另一方，投资方就担心事后被压价。这个机制把产权配置与投资激励连在一起。它为下一章的形式模型提供了直觉。

配置有两种基本安排。第一种是投资方持有资产。第二种是交易对方持有资产。第一种安排下，投资方承担投资的全部收益和全部风险。第二种安排下，投资方只能通过契约分享收益。分享比例由谈判决定。谈判比例又取决于双方的替代选择。

两种安排的比较给出一个方向。当专用性投资很重要时，把控制权给投资方更有效。当专用性投资不重要时，控制权的配置影响很小。这个方向是经验研究的起点。它也说明为什么现实中的产权安排差别很大。

# 第二章 一个形式模型

本章把第一章的前提写成一个可计算的环境。我们先给出设定。然后求均衡。最后比较两种契约安排。模型很小，只包含一个投资决策。模型的用处是把直觉变成可检验的含义。

上一章留下两个概念。剩余控制权和有限描述假设。本章把它们变成变量和约束。控制权变成一个分配参数。描述不完全变成不可验证的投资。读者会看到概念如何进入一阶条件。

## 2.1 模型设定

委托人选择专用性投资水平 x。投资成本是 c(x)。假设 c(x) 是严格凸函数，并且 c(0) 等于 0。投资提高交易对方获得的收益 v(x)。假设 v(x) 是严格凹函数，并且 v(0) 等于 0。双方先签订契约，再投资，最后重新谈判。契约只能规定一个初始价格。投资水平无法写入契约，因为第三方无法验证。这一设定把有限描述假设变成一个可计算的环境。

时序如下。第一期双方签约。第二期委托人选择投资。第三期状态实现。第四期双方重新谈判。第五期交易完成。契约只在第一期起作用。它规定初始价格和一个分配规则。分配规则无法以投资为条件，因为投资不可验证。

假设的作用如下。c 的凸性保证二阶条件成立。v 的凹性保证一阶条件给出内部解。c(0) 等于 0 和 v(0) 等于 0 保证不投资时收益为零。重新谈判保证事后的分配是有效率的。无效只出现在事前投资上。这一点是模型的核心。

模型省略了几件事。它省略了多个投资方。它省略了风险厌恶。它省略了长期关系。这些省略让模型可以解出闭式结果。它们也限制了模型的适用范围。我们在解释结果时记住这些限制。

## 2.2 均衡与结果

一阶条件给出最优投资水平 x*。在契约完全时，x* 满足边际收益等于边际成本。在契约不完全时，投资方只得到新增收益的一部分。于是 x* 低于最优水平，投资不足出现。这个结果给出可检验的含义。剩余控制权越偏向投资方，投资越接近最优。

比较静态给出三个方向。第一，专用性越强，投资不足越严重。第二，谈判力越弱，投资不足越严重。第三，初始价格越接近成本，投资不足越轻。三个方向都可以用数据检验。它们也是政策讨论的依据。

数据显示，专用性投资水平提高了 12%，样本期为 1980 年至 1990 年。数据还显示，控制权配置改变之后，投资调整在两年内完成。这个结果与模型的第一个方向一致。它也与第二个方向一致。样本的局限是它只覆盖制造业。服务业的专用性投资难以测量。

模型没有回答一个问题。为什么现实中存在混合安排。一种解释是投资是多维的。不同维度的投资需要不同的控制权。另一种解释是契约可以部分验证。部分验证降低了投资不足的程度。这两种解释都指向同一个方向。控制权的配置要配合投资的性质。
