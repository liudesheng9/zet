# 符号表任务说明

你为《{{KEY}}》选出全书的符号表。本说明之后附上任务文件：定义和公理的开头，以及原书中引入记号的句子（带文件和行号）。只读任务文件，不读别的文件。

## 选什么

- 选全书反复使用、读者要记住的符号：集合、函数、算子、常数、关系。
- 同一个符号在不同章节有不同含义时，写成两项，并在 `meaning` 里写明各自的章节。
- 不选只在一个证明里临时用的字母。
- 最多选 80 个。

## 每项写什么

- `symbol`：符号，用 `$...$`，如 `$\mathbb{R}$`、`$\sup S$`。
- `meaning`：一句中文，最多 30 字。
- `unit`：引入它的单元编号，如 `定义 4.3.1`。不知道时写空字符串。

## 结果文件

用写文件工具把 JSON 写到任务文件给出的路径（只写这一个文件）：

```json
{"symbols": [{"symbol": "$\\mathbb{R}$", "meaning": "实数集", "unit": "公理 1.3.3"}]}
```

反斜杠在 JSON 里写成 `\\`。写完后只回复一行 JSON：`{"symbols":N}`。
