## 步骤（全程最多 4 条命令）

每张卡下面已经列出"候选目标"：用词最接近、尚未链接、属于其他部分的卡片。多数链接应当从这里选，不必自己搜索。

1. **核实（一条命令）**：用助手脚本 `get_card` 一次读出你打算链接的候选目标正文（可在同一条命令里加几条 `Select-String`，查候选之外确有必要的概念），确认关系成立。
2. **精读（可选，一条命令）**：只在需要原文佐证时读相关小节段落。
3. **写入（一条命令）**：一次写完全部链接；失败时按 resume 行重跑算作第 4 条。
4. **回复**一行 JSON。

不要逐张卡片地读写，也不要为确认写入结果再读一遍。

弄清你这一部分在全书论证中的位置：

- **承接**：它依赖前面哪些部分的概念、模型或结论？
- **引出**：后面哪些部分以它为前提、推广它或把它用到新问题上？
- **同一机制**：同一机制（剩余控制权、敲竹杠、控制权配置……）在哪个领域再次出现（企业边界 ↔ 财务结构 ↔ 破产 ↔ 投票权）？
- **张力**：哪里有对比、限定、反例或作者的自我修正？

## 写链接

- 只修改你负责的卡片（清单之外的修改会被助手脚本拒绝）。用 `append_card` 在正文末尾追加一段，不重写原文：
  `{"tool":"append_card","arguments":{"at":"13/1","text":"关联：……"}}`
- 每张卡追加 1–3 条**跨部分**链接，目标是**其他部分**的卡片（其他组的文献树笔记、其他章节的主题卡、其他部分的锚点卡、人类工作区卡片）。不要重复卡片里已有的链接。
- 每条链接放在一句说明关系和理由的话里，写出逻辑链，而不是只说"相关"：
  - `承接 [[12/1]]：正因为契约无法写明所有情形，剩余控制权才有价值，本卡的所有权定义以此为前提。`
  - `同一机制见 [[36/1]]：破产程序同样是在契约不完全时重新配置控制权，只是对象换成了债权人。`
  - `与 [[30/1]] 形成对照：那里约束管理层的是债务的硬性偿付，这里是表决权；两者都在替代无法订立的完备契约。`
- **模型卡**（卡片索引中标 `[模型]`）：你的卡若推导、解释、推广或批评某个模型，而尚未链接该模型卡，必须补上，并说明涉及模型的哪一部分。**事件卡**（标 `[事件]`）：你的卡若以某个真实事件为证据或例子，链接它。
- 你的**锚点卡**追加一段，以"在全书中的位置："开头，用 2–4 句说明本部分承接哪些部分、引出哪些部分，并链接对应的锚点或关键卡片，说明理由。
- 只链接已存在的地址；人类工作区卡片可以链接但不能修改。不建主题、不移动、不删除。确有必要时，可以在你的卡片下用 `create_successor`（`kind: side`）建一张"连接卡"，专门解释两部分之间的关系。

## 写入命令

一条 pwsh 命令写完全部修改（`'@` 单独占一行、顶格），末尾照抄组信息中的 `-Allow` 参数：

```
@'
[{"tool":"append_card","arguments":{"at":"…","text":"…"}}, …]
'@ | pwsh -NoProfile -File "{{HELPER}}" - -Allow "…"
```

失败时输出 `N error …` 和 `resume: -From N -Addresses …`：只修改第 N 个调用，在命令末尾加上这两个参数重跑。

完成后只回复一行 JSON，不加其他文字：
`{"group":N,"cards_linked":修改的卡片数,"links_added":新增链接数,"errors":"无或一句话"}`
