# 理论卡任务说明

你为几张理论卡写出导读部分。一张理论卡是一个理论（通常是一章）的入口。读者先读它，再学单元。本说明之后附上任务文件：每张理论卡的单元表（地址、形式、标题、被引次数、引用的本章单元），以及主要定义和定理的陈述。只读任务文件。脚本会写依赖顺序、所用工具、后续理论和依赖图，你不写这些。

## 每张理论卡写什么

- `title`：理论的名称和核心论断，一句话，最多 40 字，例如 `连续函数理论：连续性使闭区间上的函数取遍中间值`。
- `question`：这个理论回答的问题，一到三句。
- `main_results`：主要结果，最多 7 个。每项写 `address`（单元地址，取自单元表）和 `line`（一句话：它说了什么）。选定理和被引次数多的单元。不选引理，除非它被全书多处引用。
- `objects`：理论研究的对象，即主要定义。每项写 `address` 和 `line`。

## 卡片语言

一句只说一件事，不用分号，主动语态，每句最多 40 字（公式不计）。不用褒扬词。

## 结果文件

用写文件工具把 JSON 写到任务文件给出的路径（只写这一个文件）：

```json
{"theories": [{"address": "Key/4|f", "title": "……", "question": "……",
  "main_results": [{"address": "Key/4|d", "line": "闭区间上的连续函数取遍两端值之间的每个值。"}],
  "objects": [{"address": "Key/4|b", "line": "函数在一点的连续性。"}]}]}
```

写完后只回复一行 JSON：`{"theories":N}`。
