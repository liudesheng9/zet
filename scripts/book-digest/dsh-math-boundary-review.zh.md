# 复核补写的边界分卡：任务说明

别的代理为几个数学单元补写了例子、非例或反例。原书没有给出它们。你逐张核对它们是否严格成立。你不改卡片，只写一个结果文件。本说明之后附上任务文件：每张补写的分卡，以及它所属单元的模型卡正文。只读任务文件。

## 逐张核对

- **例子**：对象满足定义的每个条款。逐条验证。
- **非例**：对象恰好违反写明的那个条款，并满足其余条款。
- **反例**：对象满足单元的其余全部假设，不满足去掉的那个假设，而且结论确实不成立。
- 计算的每一步都要成立。

全部成立，判 `ok`。有任何一处不成立或说不清，判 `wrong`，在 `reason` 里用一到两句中文写出哪一处不成立。宁可判 `wrong`，也不要放过一个错的反例：错的反例会教错读者。

## 结果文件

用写文件工具把 JSON 写到任务文件给出的路径（只写这一个文件）：

```json
{"verdicts": [{"address": "Key/4|d|d", "verdict": "ok"}, {"address": "Key/4|b|c", "verdict": "wrong", "reason": "f 在 0 处连续，不违反 (C2)。"}]}
```

写完后只回复一行 JSON：`{"ok":N,"wrong":M}`。
