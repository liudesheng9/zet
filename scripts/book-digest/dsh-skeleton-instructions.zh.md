# 骨架任务说明

一本书（文献卡 `[[{{KEY}}]]`，ZET 代理工作区）已经消化成卡片。脚本将为它写三样东西：文献卡上的全书索引、全书的结构卡、本书为主的主题的正文。脚本已经搭好框架。你只写其中的短文字，作为一个 JSON 文件。你不调用 zt，不改动任何卡片。

本说明之后附上任务文件：各组的锚点卡（标题与正文）、本书的模型卡、事件卡，以及本书为主的主题（现在的正文与树中的卡片）。**只读必须读的**：任务文件已经给出所需的全部内容，不要浏览文件夹。

## 你的输出

把结果写入任务文件指定的 JSON 文件（UTF-8）：

```json
{"chapters": [{"anchor": "{{KEY}}/1", "says": "这一组讲了什么（一句，最多 40 字）"}],
 "argument": [{"anchor": "{{KEY}}/1", "adds": "这一部分为全书论证加了什么，它怎样承接上一部分（一到两句）", "key_cards": ["12/1", "{{KEY}}/1|a"]}],
 "models": [{"address": "{{KEY}}/3|a", "shows": "这个模型说明什么（一句，最多 40 字）", "built_on_by": ["{{KEY}}/5|a"]}],
 "events": [{"address": "{{KEY}}/2|b", "supports": ["12/1"]}],
 "topics": [{"root": "12/0", "body": "本主题追问：……。……。入口：依赖 [[12/1]] 的定义……"}]}
```

- `chapters`、`argument`：每个锚点卡一项，按书中顺序。`key_cards` 选一到三张最重要的卡片（只能用任务文件中出现的地址）。
- `models`：每张模型卡一项。`built_on_by` 列出以它为基础的后面的模型卡（没有就写空列表）。
- `events`：每张事件卡一项。`supports` 列出它作为证据支持的观点卡（只用任务文件中该事件卡链接的地址）。
- `topics`：每个主题一项。正文两到三句：这个主题追问什么问题。然后用带关系词的句子链接一到三张入口卡（只用该主题树中的卡片），关系词放在 Link 前（`依赖`、`例示`、`对照` 等）。不要写枢纽卡的内容，脚本会保留正文中链接枢纽卡的行。
- 只用任务文件中出现的地址。不要编造地址。
- 写完文件后，只回复一行 JSON：`{"chapters":数,"argument":数,"models":数,"events":数,"topics":数}`。

## 卡片语言

遵守 `asd-ste100-zh` 技能：一句只说一件事，描述句最多 40 字（Link 和公式不计），不用分号，主动语态，动作用动词，保留原书的语气，不用褒扬词。
