# 术语同步任务

书架上有一张标准术语表。一本新书的术语表由另一个代理写成，同一个概念可能用了不同的写法。你的任务是找出新书的哪些术语与标准表的术语等义。下面每个本书术语行后面跟着脚本找到的几个候选标准术语。定下的等义关系会成为两本书术语卡之间的链接。术语本身不改。

## 工作方式

你在一次对话里按顺序做完全部步骤。判断要用的材料全在本条消息里：这份说明和下面的术语行，第 4 步的命令再给你真实句子。

1. **想两遍，都在推理里做，不用工具，不读文件，不写脚本。** 第一遍逐行看本书术语和它的候选，选出是同一概念的那一个。第二遍只看你选中的行，逐行核对“意思”。
2. **一次写完草稿** 到 `{{ANSWER}}`。
3. **运行一次 REVIEW 命令：**
   ```
   {{REVIEW}}
   ```
   它先列出 faults，再为每个选中的行给出书里的原句和标准表的说明。
4. **读这些句子，逐行判断。** 句子说的不是同一个东西，或一边的词比另一边宽、窄，就从答案里删掉这一行。
5. **草稿有改动才重写一次，再运行一次 REVIEW。** faults 是 0 就结束，不再复查。

## 判断

- **同一概念才算等义。** 同一个人物、地点、制度、教派、事件或概念，换了写法：音译差一个字、意译与音译、简称与全称。
- **宽窄不同不算等义。** “精英”和“统治精英”、“辩论”和“学术辩论”、“史料”和“书面史料”都不算。
- **时段、国家、制度三者不等义。** “前伊斯兰时期”和“蒙昧时代”、“哈里发国”和“哈里发制度”不算。
- **候选里没有同一概念，就不写这一行。** 脚本会把它加进标准表，成为新的条目。这是正常结果，不是遗漏。
- **拿不准就不写。** 漏掉一行只是少一条链接，错配一行会把读者带到另一个概念。
- **你只选候选，** 不创造新写法。

## 输入格式

每个本书术语一行，用制表符分隔：行号、术语、不用词（顿号分隔）、意思、用量。下面缩进的行是它的候选：编号、标准术语、异写、意思。

## 输出

写入 `{{ANSWER}}`（UTF-8）：

```json
{"align":[{"row":"R34","to":"s120"}]}
```

- `row` 和 `to` 照抄编号，不写术语。
- 一个标准术语只对应本书一行。
- 结束时只回复一行 JSON：`{"align":等义的行数}`。
