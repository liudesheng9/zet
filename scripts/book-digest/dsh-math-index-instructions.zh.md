# 找出数学陈述（数学消化流程）

你为《{{TITLE}}》（{{KEY}}）找出原文里的数学陈述。本说明之后附上任务文件：几个原文文件，每行带行号。只读任务文件，不读别的文件，不上网。

后面的阶段为你找出的每个定义和结果建一张模型卡（单元），由原文写出它的陈述、证明和例子。所以这一步要找全，也要找准：漏掉的陈述不会有卡片，找错的陈述会得到一张空的卡片。

## 什么算陈述

书怎样写都算，有编号或没有编号都算。看内容，不看格式。

- **definition（定义）**：书第一次说清一个概念、记号或运算是什么。例如“我们把 x 的一小部分记作 dx”“这种曲线叫作对数曲线”“$\int$ 读作……之和”。书用一个例子来说明概念时，说明概念的那几行是定义，例子另记为 example。
- **axiom（公理）**：书不加证明、直接作为出发点的约定或基本规则。
- **theorem（定理）**：书的主要结果，对一类情形都成立的一般规则。例如“$x^n$ 的导数是 $nx^{n-1}$”、乘积的求导法则、两个自变量函数取极大值的条件。
- **proposition（命题）**：其他一般规则，比定理次要。
- **lemma（引理）**：只为证明另一个结果而说出的辅助结果。
- **corollary（推论）**：由一个结果直接得出的结果。
- **example（例）**：一道算出具体数字或具体式子的例题，或一个具体对象。它不是一般规则。
- **exercise（习题）**：留给读者做的题目。一组编号相同的题（如“练习 III”）记为一项。

书自己用了词（定义、定理、法则、规则、公式、“叫作”“称为”“记作”）时，按书的词选种类。书没有用词时，按上面的意思选。

## 什么不算

- 动机、历史、闲谈、对读者的鼓励。
- 只对一个具体数字成立的计算：它是 example，不是 theorem。
- 同一个结果在后面又说一遍：只记第一次完整说出的地方。
- 目录、版权页、转录者注、答案页里的单个答案。答案页的一组答案不记为习题。
- 书里没有的内容。不补写，不推广。

## 每项写什么

- `kind`：上面八种之一，用英文小写。
- `label`：书自己的编号或名字，原样照抄，如 `定理 3.2`、`练习 III`、`情形 2`。书没有给时写空字符串。
- `name`：中文短名，最多 20 字，说清它是什么，如 `乘积的求导法则`、`微分 dx`。同一任务里的两项不同名。
- `section`：文件名，如 `s08.md`。
- `line`：陈述开始的那一行的行号。
- `end`：这一项最后一行的行号。定理或规则包括书给出的推导或证明；例题包括它的解。两个定义或结果的行不重叠：前一项在后一项开始之前结束。例和习题可以落在它所服务的结果的行内。
- `proof`：书证明或推导这个结果的第一行的行号，在 `line` 之后、`end` 以内。书没有给出证明时写 0。定义、公理、例和习题写 0。
- `quote`：从 `line` 那一行原样抄下 8 到 20 个字，不加不改。检查用它确认行号。
- `cites`：这个定义或结果用到的其他陈述，写它们的 `label`，没有 label 时写它们的 `name`。只写本任务里的陈述，或书明确提到编号的陈述。没有时写 `[]`。
- `belongs_to`：只用于例和习题：它服务的那个定义或结果的 `label` 或 `name`。不清楚时写空字符串。
