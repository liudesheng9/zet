# 图像说明任务说明

你看一本书里的图像，为每张图像写一段中文说明，告诉没有看到图的读者：这张图是什么，它画了或列了什么，读者能从中看出什么。这段说明会存在原图旁边，读者点开图时读到，图表卡片也靠它判断哪张卡片该配这张图。

本说明之后附上**本组任务文件**：书名、答案路径、SELF-CHECK 命令，以及每张图像的编号、图注和书中上下文。图像本身作为附件给你，顺序与任务文件的编号相同。你只写一个 JSON 文件，不调用 zt，不改别的文件。

## 怎么写

- **自己看图。** 说明来自你在图上看到的东西。图注和上下文只帮你认出图的主题，不要复述它们。
- **说图的内容，不抄图上的字。** 不要逐行抄写图里的文字、图例或表格。图上有地名、人名、数字时，挑几个能说明要点的写进句子里。
- **按图的种类说要点：**
  - 统计图：图的类型，横轴和纵轴各是什么，有哪几条线或哪几组，主要的走势、高低或差距，用图上读得出的数说明。
  - 地图和平面图：画的是哪里，主要标出了什么，方位和相互位置关系。
  - 照片和绘画：拍或画的是什么，主体、场景和看得出的细节。
  - 示意图和流程图：有哪些部分，它们怎样连接，表达什么关系。
  - 表格图像：表的主题，行和列分别是什么，最值得注意的比较。
  - 文字图像（手稿、碑铭、书页、海报）：是什么材料，什么文字，版式如何，大意是什么；读不清的就说读不清，不要猜，不要抄写。
  - 标志（出版社标记、印章、条形码、装饰花纹）：一句话说明它是什么。
- **看不清的地方直接说看不清。** 不写图上没有的东西，不下图上得不出的结论。
- 中文写，一般 60 到 300 字，内容复杂的图可以更长，上限 1500 字。

## 字段

- `image`：第几张，从 1 开始，与任务文件一致。
- `kind`：只能是 `chart`（统计图）、`map`（地图、平面图）、`photo`（照片、绘画）、`diagram`（示意图、流程图）、`table`（表格图像）、`text`（文字图像）、`logo`（标志、印章、条形码、装饰）、`other`。
- `title`：一个不超过 40 字的短标题，说明图的主题。
- `explanation`：说明正文。

## 答案

把结果写入任务文件给出的答案路径（UTF-8 的 JSON），一次写完，每张图一项：

```json
{"images": [{"image": 1, "kind": "map", "title": "九世纪巴格达城区平面图", "explanation": "这是一幅……"}]}
```

## 自查

写完后原样运行任务文件里的 `SELF-CHECK:` 命令。每行是一个问题，最后一行是 `faults: N`。改到 `faults: 0`，最多运行三次。`ocr_copy` 表示说明抄了图里的文字：重新看图，用自己的话写。

## 回复

只回复一行 JSON：`{"images":图像数,"errors":"无或一句话"}`
