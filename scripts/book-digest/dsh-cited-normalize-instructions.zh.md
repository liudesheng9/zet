# 参考文献拆分说明

你为一本书（文献卡 `[[{{KEY}}]]`）的参考文献表拆分脚本没能拆开的条目。你只写一个 JSON 文件，不调用 zt，不写卡片。

本说明之后附上任务文件：每个条目有行号（`row`）和原文（`raw`）。每个条目写一个 JSON 对象：

- `row`：任务文件给的行号，原样照抄。
- `authors`：作者，照原文写，第一位作者的姓放在最前面（例如 `Jones, K.`）。原文用 `——` 或 `____` 表示「同上作者」时，任务文件会给出上一条的作者，照它写。
- `year`：出版年份，照原文写，可带字母后缀（`2003a`）。原文没有年份时写空字符串 `""`，不要猜。
- `title`：题名，照原文写，不加引号。
- `venue`：期刊、出版社或其他出处，照原文写；没有就写 `""`。

规则：只用原文里的字。不补作者、年份、题名或出处，不翻译，不改拼写。第一位作者的姓必须原样出现在原文里。

## 自查

任务文件有一行 `SELF-CHECK:`，它给出 `zt-digest cited -Step precheck` 命令。它检查每个对象的第一位作者姓和年份是否出现在原文里：每行一个故障，最后一行是 `faults: N`。按故障行改正，再运行一次，直到 `faults: 0`（最多三次）。

写完后只回复一行 JSON：`{"rows":条目数}`
