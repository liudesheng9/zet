## 模型卡

按 skill 中的"Event Cards and Model Cards"一节撰写模型卡，用 `create_successor` 的 `"type":"model"` 标明类型。本书的事件卡由事件层另行写出，你不写事件卡。`create_successor` 另有 `type` 和 `level` 两个参数，只用于模型卡。

- **模型卡**（`"type":"model"`）：你的小节提出的每个完整模型（形式模型，或有明确假设的概念模型）写一张，并用 `"level"` 标明它的**细化层级**（见下条），放在你的锚点下作侧后继，且在批处理中**排在讨论它的卡片之前**。正文依次为：问题；设定；假设；时序与信息；求解或均衡；主要结论；直觉；局限；来源（写明小节号，如 `来源：[[{{KEY}}]] §2.2`）。可写到 1200 字左右。每个模型只写这一张完整的模型卡：本组结束后，会有专门的阶段对照原文核实它，自行决定模型的结构（需要哪些模型分卡、各自叫什么、谁依赖谁、哪些是核心），并配上图表，所以你**不要**传 `facet` 或 `emphasis`，也不要自己拆分。
- **细化层级**（`level`）：
  1. `"formal"`（第 2 层，形式模型）：原书用数学给出模型，即有符号、方程、推导、带证明的命题，或要靠代数算出的数值例子。模型阶段会把它建成自足模型，补上书中略去的推导步骤。
  2. `"concept"`（第 1 层，概念模型）：原书用文字或示意图给出模型，即一个机制、一个分类、一个框架或一段文字论证。原书只引用或概述一个形式模型而不推导它，也算概念模型。模型阶段只核实它，不加推导分卡。
  3. `"empirical"`（第 3 层，实证模型）：原书**自己用数据估计或测量**一个关系，即给出数据、估计式或识别设计，并报告估计值及其标准误、显著性或置信区间（回归表、事件研究、工具变量、断点、随机实验、结构估计、作者构造并验证的测量）。模型阶段按证据链建它：数据、设计、规格、各章估计、检验，估计值的数字由脚本从原书表格写入。正文依次为：问题；估计对象（什么对什么的效应或关联，对谁）；设计；数据；估计式；主要估计（数字照原书抄写，带标准误和表格列）；检验与稳健性；局限；来源。
  原书在同一小节先推出理论、再用数据检验它时，写两张模型卡：一张 `"formal"`（或 `"concept"`）的理论模型，一张 `"empirical"` 的检验，后者用 `对应 [[理论模型卡]]：检验它的预测` 链接前者。原书只转述别人的估计、只给一个数或一个计数时，不写实证模型：那是实证结果，由实证结果层写成 Finding Card。
  拿不准形式与概念时写 `"formal"`，模型阶段会复核。
- **讨论模型的卡片**（推导、结论、解释、推广、批评，都在本书的文献树里）**都必须链接该模型卡**，并说明涉及模型的哪一部分。ZET 从 Link **紧前的词**读出关系类型，所以把关系词写在 Link 前：推导或用到它写 `依赖 [[@@0]] 的设定：……`，举例或应用写 `例示 [[@@0]]：……`，推广或放宽假设写 `放宽 [[@@0]] 的……假设：……`，比较写 `对照 [[@@0]]：……`，类比写 `对应 [[@@0]]：……`，批评写 `反驳 [[@@0]]：……`。模型若由其他组提出，链接其锚点或快照中的模型卡。

- 由模型推出的内容写成一张散文笔记，用一句说明这段在做什么，并链接模型卡（`该推导见 [[模型卡]]`）；不要把推导步骤再抄一遍。事件和实证结果同样处理：笔记写上下文，链接那张卡。
- 回复的那行 JSON 再加两个字段：`"models":模型卡数,"events":事件卡数`。

**模型卡写出完整的设定。** 写明参与者、时序、信息和全部符号的含义。不要写 `沿用某模型的设定` 而不写出设定：读者只读这张模型卡，也要知道模型的前提。
