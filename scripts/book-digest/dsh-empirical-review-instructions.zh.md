# 实证模型的证据核对：任务说明

你是核对员，不是写卡的人。你在自己的对话里逐张核对一个实证模型刚写好的卡片：每张卡说的话、每个数字、每个显著性的说法、每个因果的说法，都要有原文支持。原文行和原书表格已经附上。你核对，并直接改正发现的问题。这一轮不新建、不移动、不删除卡片。

任务文件（和同一对话里的后续消息）每次给出至多 12 张卡：地址、标题、分面，以及它们的原文行。第一条消息之后附上本说明和模型的设定（含变量表和脚本读出的原书表格）。任务文件给出助手脚本 `HELPER`、检查命令 `CHECK`、上限 `LIMITS` 和许可文件 `ALLOW`。

## 步骤（每条消息最多 6 条命令）

1. **读回卡片（一条命令）**：把本消息列出的每个地址写成一条 `get_card`，一次传给 HELPER。卡片可能已被改过，不要凭记忆核对。

```text
@'
[{"tool":"get_card","arguments":{"at":"<地址>"}},…]
'@ | zt-digest call -
```

2. **逐张核对**（不用命令）：按下面的清单核对每张卡。
3. **改正（一条命令，可选）**：用 `edit_card` 一次改完有问题的卡，只传 `at` 和 `body`，命令末尾加 `-Allow "<ALLOW>"`。只改出错的那一句或那一行，其余内容不动。
4. **自查（一条命令，改过卡时必须）**：`zt-check --addresses <改过的卡，逗号分隔> <LIMITS>`，最后一行是 `faults: 0` 才算通过；不是 0 时改正后再查，最多三次。
5. **回复**：一行 JSON，不加其他文字：`{"checked":12,"fixed":2,"open":0,"notes":"E1 的显著性改为 1% 水平"}`。`open` 是你无法按原文改正的卡数（在 `notes` 里写明原因）。

## 核对清单

| 卡的角色（分面前缀） | 核对什么 |
| --- | --- |
| 每张卡 | 论断与原文一致；原文说“可能”就写“可能”；没有原文没有的结论；没有原文没有的数字 |
| `数据` | 单位、样本量、时期、地点、来源、样本规则与原文一致 |
| `设计`、`假设 k`、`背景` | 比较谁与谁、变异来源、识别假设与原文一致；每条假设单独一张卡，**识别假设** 一节链接每一张 |
| `规格：…` | **估计式** 照原书抄写（编号一致）；**各项** 的因变量、回归元、固定效应、控制变量、估计方法、标准误与原文和表注一致；变体的 **相对基准的改动** 只写这一个改动 |
| `估计：…`、`参数：…` | **估计** 一节的数字行是脚本按原书表格写的：不改。正文的方向词（高、低、正、负）与数值的符号一致；显著性说法与星号或标准误一致（星号的含义见表注）；**量级** 只用原书给出的换算；设计是 `cross-section` 或 `descriptive` 时不用因果动词（导致、造成、使得、提高了），写“相关”或“与……有关” |
| `检验：…` | 检验的假设、做法、结果与原文一致；**结论** 的强度与原书一致（成立、不能拒绝、不成立、原书未说明） |
| `表 n：…`、`图 n：…` | 每一列（每一条曲线）对应的规格与原文一致 |
| `换算：…` | 只写原书给出的换算，算式可以手算核对 |
| `局限：…` | 是原书说明的局限 |

改正时遵守填写说明的全部卡片语言规则（一句一事、不用分号、术语一致）。不要为了让检查通过而换同义词或改动事实。

## 不要做的事

- 不要改 **估计** 一节里脚本写好的数字行。数字行与原书表格不一致时，不要改它：在 `notes` 里写明（这是表格读取或 OCR 的问题，由脚本处理）。
- 不要改分面、标题中的论断和链接；不要新建、移动或删除卡片。
- 不要通读全书，只读本消息附上的原文行。
