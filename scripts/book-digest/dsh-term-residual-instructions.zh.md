# 术语替换复核任务

一组历史书的术语已经对齐。脚本替换了安全的地方，下面这些出现处它拿不准，由你判断。中文没有词界，所以一个词可能只是看起来像：“瓦拉”可能是“瓦拉什一世”的一部分，“明教”可能是“说明教法”的一部分。

## 工作方式

判断要用的材料全在本条消息里。

- 不读取、不列出、不搜索任何文件，不写脚本。
- 想两遍，都在推理里做：第一遍逐行判断；第二遍只看你打算替换的行，确认替换后句子仍然通顺、意思不变。
- 然后一次写完答案文件，运行一次 SELF-CHECK。只有 faults 不是 0 才改答案再运行；faults 是 0 就结束。

## 判断

每行是一处出现：编号、词→术语、前后文，词在【】里。

- **替换：** 这个词在这里指的就是该术语的概念，换成术语后句子通顺。
- **不替换：** 这个词是别的词的一部分，或这里指别的东西，或句子在引用书名、原文，或说的就是这个写法本身（例如“亦称……”“旧译……”）。
- 拿不准就不替换。

你不改写句子。你只列出要替换的编号，脚本在原位替换。

## 输出

写入 `{{ANSWER}}`（UTF-8）：

```json
{"replace":["o12","o57"]}
```

- 编号照抄，不要自己编。不替换的编号不写。
- 写完运行 SELF-CHECK：
  ```
  {{CHECK}}
  ```
- 结束时只回复一行 JSON：`{"replace":要替换的处数}`。
