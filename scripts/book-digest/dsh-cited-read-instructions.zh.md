# 参考文献读取说明

你为一本书（文献卡 `[[{{KEY}}]]`）读它的参考文献部分，把每一篇文献写成一个条目。原文经过 OCR，所以一行可能含几篇文献，一篇文献也可能跨几行；同一段文字可能重复出现；也可能夹着说明文字或页眉。你只写 JSON 文件，不调用 zt，不写卡片。

本说明之后附上任务文件。每段任务文件列出原文行，每行以行号开头（`L7445: …`）。一个任务分几段，每段是一条消息。读完一段就写这一段的 JSON 文件并自查，然后等下一段。

## 每篇文献写一个条目

- `lines`：这篇文献所在的行号（数字，不带 `L`）。一篇文献跨几行时列出每一行。一篇文献从上一段的最后一行开始时，可以写上一段的行号。
- `entry`：这篇文献的完整文字，从原文**逐字照抄**：不改拼写、不补字、不删字、不翻译，不改标点。一行里有几篇文献时，把它们分开，每篇只抄它自己的那一部分。不要抄行首的行号。
- `authors`：作者，照原文写，第一位作者的姓放在最前面（例如 `Kennedy, H.`）。没有个人作者时（编年史、匿名作品）写 `""`。`entry` 以 `——` 或 `—` 开头（表示「同上作者」）时，写出它重复的作者：通常是上一个条目的作者。
- `year`：出版年份，照 `entry` 里的写法（`1999`、`2003a`、`1920–1`、`1968–75`）。原文写了重印年份时，取第一个出版年份。`entry` 里没有年份时写 `""`，不要猜。
- `title`：题名，从 `entry` 照抄，不带引号。
- `venue`：期刊、文集、出版社或出版地，照原文写；没有就写 `""`。

## 不是文献的行

说明文字、页眉、页码、标题、空的编号，以及只有「见某处」的交叉引用（例如 `Fihrist: see al-Nadīm.`），不写条目，把它们的行号写进 `skip`。

**重复的文献也照写。** 原文重复的段落，每一篇照样写条目。删除重复由脚本完成，你不用判断。

## 你的输出

把这一段的结果写入任务文件指定的输出文件（UTF-8）：

```json
{"entries":[{"lines":[7445],"entry":"‘Abd al-Ḥamīd b. Yaḥyā al-Kātib, Risāla, in, ed. Muḥammad Kurd ‘Alī, Rasā’il al-Bulaghā’ (Cairo, 1946), 173–210.","authors":"‘Abd al-Ḥamīd b. Yaḥyā al-Kātib","year":"1946","title":"Risāla","venue":"Rasā’il al-Bulaghā’ (Cairo)"},{"lines":[7460],"entry":"——Kitāb al-Aghānī, ed. Muḥammad Hatim (Cairo, 1963).","authors":"al-Iṣfahānī, Abū’l-Faraj","year":"1963","title":"Kitāb al-Aghānī","venue":"Cairo"}],"skip":[7443]}
```

这一段的每一行都必须出现在某个条目的 `lines` 里，或者在 `skip` 里。

## 自查

任务文件有一行 `SELF-CHECK:`，它给出 `zt-digest cited -Step precheck` 命令。原样照抄，写完就运行。它检查：每个 `entry` 是否逐字出自它的行；第一位作者的姓、年份和题名是否在 `entry` 里；这一段的每一行是否都有着落。每行一个故障，最后一行是 `faults: N`。按故障行改正，再运行一次，直到 `faults: 0`（最多三次）。

写完后只回复一行 JSON：`{"entries":条目数,"skip":跳过的行数}`
