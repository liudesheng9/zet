# 孤立卡片任务说明（所有任务共用）

ZET 卡片盒中一本书（文献卡 `[[{{KEY}}]]`，代理工作区）有一些卡片没有被父卡以外的卡片链接。读者只能从父卡走到它们。你的任务是：为每张孤立卡片找一张最相关的卡片，并在那张卡片的正文末尾追加一句带理由的链接。你只写一个 JSON 文件，不调用 zt，不改动任何卡片：脚本读你的文件，核对后再写入。

本说明之后附上你的任务文件。任务文件给出每张孤立卡片的标题和正文，以及 3–5 张候选卡片（地址、标题、正文摘录）。

**只读必须读的。** 任务文件已经给出选择所需的全部内容。不要浏览文件夹，不要读其他文件。读完任务文件就写 JSON 文件。

## 你的输出

把结果写入任务文件指定的 JSON 文件（UTF-8）。只写这一个文件。格式：

```json
{"links": [
  {"to": "40/1|a", "from": "41/2", "text": "对照 [[40/1|a]]：那里的决定权来自所有权，这里来自合同条款。"}
],
 "none": [
  {"orphan": "40/1|c", "note": "候选卡片都与它没有真实关系。"}
]}
```

- 每张孤立卡片写一项：在 `links` 中（找到了），或在 `none` 中（候选卡片都不合适）。
- `to` 是孤立卡片，`from` 是候选卡片之一（只能从候选清单中选）。`text` 是追加到 `from` 正文末尾的一句话。
- `text` 必须包含 `[[to]]`，并在同一句中、Link **之前**写一个关系词：`依赖`/`基于`/`承接`（以它为前提）、`例示`/`案例`（举例）、`对照`/`区别`（比较）、`放宽`/`推广`（推广）、`对应`/`类比`（对应）、`反驳`/`批评`（反对）。孤立卡片是事件卡时，`from` 必须是观点卡，关系词通常是 `例示` 或 `案例`。
- 理由写出两张卡之间真实的关系，不能只说"相关"。只写一到两句。
- 写完文件后，只回复一行 JSON：`{"job":"任务编号","orphans":孤立卡片数,"links":链接数,"none":未链接数}`。

## 卡片语言

追加的句子遵守 ASD-STE100 改写成的中文规则（`asd-ste100-zh` 技能）。一句只说一件事，描述句最多 40 字（Link 和公式不计），不用分号，主动语态，动作用动词，保留原书的语气，不用褒扬词。
