# 孤立卡片任务说明（所有任务共用）

ZET 卡片盒中一本书（文献卡 `[[{{KEY}}]]`，代理工作区）有一些卡片没有被父卡以外的卡片链接。读者只能从父卡走到它们。你的任务是：为每张孤立卡片找一张最相关的卡片，并在那张卡片的正文末尾追加一句带理由的链接。你只写一个 JSON 文件，不调用 zt，不改动任何卡片：脚本读你的文件，核对后再写入。

本说明之后附上你的任务文件。任务文件给出每张孤立卡片的标题和正文，以及 3–5 张候选卡片（地址、标题、正文摘录）。

**只读必须读的。** 任务文件已经给出选择所需的全部内容。不要浏览文件夹，不要读其他文件。读完任务文件就写 JSON 文件。写完后只运行自查命令（见"自查"一节）。

## 你的输出

把结果写入任务文件指定的 JSON 文件（UTF-8）。只写这一个文件。格式：

```json
{"links": [
  {"to": "Smith2024/4|a", "from": "Smith2024/5", "text": "对照 [[Smith2024/4|a]]：那里的决定权来自所有权，这里来自合同条款。"}
],
 "none": [
  {"orphan": "Smith2024/4|c", "note": "候选卡片都与它没有真实关系。"}
]}
```

- 每张孤立卡片写一项：在 `links` 中（找到了），或在 `none` 中（候选卡片都不合适）。
- `to` 是孤立卡片，`from` 是候选卡片之一（只能从候选清单中选）。`text` 是追加到 `from` 正文末尾的一句话。
- `text` 必须包含 `[[to]]`，并在同一句中、Link **之前**写一个关系词：`依赖`/`基于`/`承接`（以它为前提）、`例示`/`案例`（举例）、`对照`/`区别`（比较）、`放宽`/`推广`（推广）、`对应`/`类比`（对应）、`反驳`/`批评`（反对）。孤立卡片是事件卡时，`from` 必须是观点卡，关系词通常是 `例示` 或 `案例`。
- 理由写出两张卡之间真实的关系，不能只说"相关"。只写一到两句。
- 自查完成后，只回复一行 JSON：`{"job":"任务编号","orphans":孤立卡片数,"links":链接数,"none":未链接数}`。自查后仍有问题时，在这一行加字段 `"left"`，列出剩下的问题行。

## 自查

任务文件有一行以 `SELF-CHECK:` 开头。冒号后面是这个任务的自查命令。自查命令按脚本以后使用的同一套规则检查你的 JSON 文件。自查命令只读文件，不改动卡片。

1. 写完 JSON 文件后，运行自查命令。原样复制命令，不要改动命令。
2. 读输出。每一行是一个问题，格式是 `地址 规则 说明`。最后一行是 `faults: N`。
3. 在 JSON 文件中修正每一个问题。
4. 再运行自查命令。
5. 最后一行是 `faults: 0` 时，回复。

- 自查命令最多运行 3 次。3 次后仍有问题时，也要回复，并在回复中用 `"left"` 列出这些问题。
- 一条链接在问题行中写作 `孤立卡片<-候选卡片`，例如 `Smith2024/4|a<-Smith2024/5`。
- 规则 `refuse` 表示脚本会拒绝这条链接，例如 Link 前没有关系词，或 `from` 不是候选卡片。规则 `entry` 表示一张孤立卡片既不在 `links` 中，也不在 `none` 中。
- 规则 `L2` 表示句子的理由太短：除 Link 外至少写 8 个字的理由。

## 卡片语言

追加的句子遵守 ASD-STE100 改写成的中文规则（`asd-ste100-zh` 技能）。一句只说一件事，描述句最多 40 字（Link 和公式不计），不用分号，主动语态，动作用动词，保留原书的语气，不用褒扬词。

## 通用写入规则（每个写卡的任务都适用）

- **保留术语写法。** 正文里已有的术语链接 `[[词@地址]]` 原样保留；要提到一个已有术语、而正文没有现成链接时，写术语本身的文字，不要自己造链接。
- **不编造、不绕过。** 不要编造地址或链接目标，也不要为了让检查通过而换同义词、换关系词或改掉事实里的用词。
- **先自查。** 任务文件给出自查命令时（`SELF-CHECK:` 行，或 `CHECK:` 与 `LIMITS:` 两行），原样照抄，写完（或改完）就运行；最后一行是 `faults: 0` 才算通过，最多运行三次。命令没有打印 `faults:` 行（或任务文件指定的状态行）时，视为没有自查。
- **`card_check` 是内容问题。** 写入被拒绝为 `card_check` 时，拒绝里的每个故障行就是要改的内容：按它们改写后再写一次，仍在这一轮限定的修正次数以内。它不是脚本、服务或网络故障，不要原样重试。
- **`card_locked` 是选址决定。** 写入被拒绝为 `card_locked` 时不要重试，不要换 Access，不要改用别的写入路径或直接改数据库：保留已写好的答案，按任务文件的要求回复，并写明被拒绝的地址。
