# Finding the division of any source

Use the source's own division when it has one, in the terms it uses. Otherwise derive one and say so in your report.

| Form | Its division | Notes |
|---|---|---|
| Book, textbook, report | Chapters, with sections inside | Parts usually yield to chapters |
| Paper | Numbered sections; abstract and front matter with the introduction | The sections are the top line |
| Lecture series, course | Lectures, with their sections inside | An added edition's new material is its own front matter |
| Edited volume, proceedings | Contributions, each with its author | Each contribution keeps its own top Card |
| Law, treaty, standard | Titles, chapters or articles, as numbered | The numbering sets the order, even when the logic runs otherwise |
| Scripture, classic with a fixed scheme | The received scheme | Commentary sits under the passage it comments on |
| Court opinion | Facts, issues, holding, reasoning, each separate opinion | A dissent is its own top Card |
| Interview, oral history, meeting | Topics in the order raised; speakers when they hold the floor at length | Derived |
| Podcast, talk, film, recording | Chapters or scenes if published, else segments by time and topic | The timestamps set the order |
| Dataset or software documentation | Its modules or tables, as its own contents page lists them | |
| Correspondence, diaries, archives | Date, or the collection's own series | |
| Unsectioned essay | The argument's moves, in order | Derived |

A derived division holds to two rules: it follows the source's order, and a reader of the source would recognize each piece as one stretch of it.
