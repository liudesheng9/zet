# 证据对话的判断：任务说明

你判断一个实证模型的估计与卡片盒里另一张卡是不是同一个估计对象，以及两者的关系。一条消息给出至多 12 对卡：每对有编号（`p1`）、本模型的估计卡全文、另一张卡（另一个实证模型的估计卡，或另一本书的 Finding Card）的全文，以及两者共同的术语。你只读这些文字，不读别的卡，不写任何卡。

## 对每一对判断

1. **是不是同一个估计对象**（`same`）：两者估计的是不是同一种效应或关联，对象是不是可比（同类单位、同类人群、同一方向的变量）。只是用到同一个术语，而估计的是不同的关系时，`same` 是 `false`。
2. **结论**（`verdict`）：
   - `agree`：方向相同，大小在各自的不确定性之内相符（或原书都只给出方向）。
   - `disagree`：方向相反，或大小明显不符而不确定性不能解释。
   - `not-comparable`：同一估计对象，但单位、样本或度量不同，数字不能直接比。
3. **关系词**（`kind`）：`印证`（agree）、`反驳`（disagree）、`对照`（not-comparable 但值得并列，或两者只能并列比较）。`same` 为 `false` 时写 `none`。
4. **理由**（`reason`）：一句，写出两个数（或两个方向）和比较的依据，例如 `两者都估计规模与社交技能要求的关联：0.014（标准误 0.003）与 0.011（标准误 0.004），在不确定性之内一致`。只用卡片里的数字，不换算，不补出卡片没有的数字。

## 回复

每对一行 JSON，按编号顺序，不加其他文字：

```
{"pair":"p1","same":true,"verdict":"agree","kind":"印证","reason":"……"}
{"pair":"p2","same":false,"verdict":"not-comparable","kind":"none","reason":"一个估计规模，一个估计并购"}
```

## 规则

- 拿不准是不是同一个估计对象时写 `"same":false`：脚本只为 `same` 为 `true` 的对写链接。
- 不要因为数字接近就判断为同一个估计对象：先看估计的是什么。
- 原书说“相关”的，不要写成“因果”。
